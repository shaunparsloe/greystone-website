# Booking.com gallery photos

All 93 photos from Greystone Guesthouse's Booking.com listing, in gallery order, at 1280×900 (the largest size Booking.com serves).

File names are `Greystone_NN_<booking-id>.jpg`. `NN` is the position in the Booking.com gallery and `<booking-id>` is Booking.com's photo ID, which matches the ID-named files already in `website/images/` (for example `541906671.jpg`).

This folder sits outside `website/`, so these files are stored in the repo but not published on the live site. To use one on the site, copy it into `website/images/` with a `.webp` version alongside, as the existing images are.
